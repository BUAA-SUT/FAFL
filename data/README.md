# Experimental Inputs

This directory contains the source test cases and supporting input artifacts
used by the eight subjects.

- TSQ, DM, SMM, KNN, and Tcas use JSON source-test files.
- PT and PT2 use `RandomInput.csv`.
- Grep uses `RandomInput.csv` together with target files and MR-mapping data.
- `iris.data` is the base dataset used by KNN.
- `universe.txt` is the base input pool used by Tcas.

For TSQ, DM, SMM, KNN, and Tcas, each JSON file preserves both the original
pool of 1,000 generated cases (`source_case_set`) and the 100 cases selected for
the experiment (`random_input`). The original Python drivers set
`random.seed(1)` before randomized selection or MR operations. PT, PT2, and
Grep preserve the selected tabular inputs directly in their CSV files; their
drivers and randomized MR implementations also use seed 1 where applicable.

Follow-up test cases are generated by the executable MR definitions under
[`../code/`](../code/). See [`../docs/SUBJECTS.md`](../docs/SUBJECTS.md) for
the exact subject-to-file mapping.
