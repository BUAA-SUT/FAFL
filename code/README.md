# Experiment Code

Each subject directory contains the MR implementation and experiment driver.
Selected faulty versions are stored under its `mutants/` directory. PT, PT2,
and Grep also include subject-specific execution and statement-coverage
utilities.

See [`../docs/SUBJECTS.md`](../docs/SUBJECTS.md) for the artifact map,
[`../docs/METAMORPHIC_RELATIONS.md`](../docs/METAMORPHIC_RELATIONS.md) for MR
semantics, and [`../docs/REPRODUCIBILITY.md`](../docs/REPRODUCIBILITY.md) before
running the original experiment drivers.
