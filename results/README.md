# Experimental Results

## `all-techniques.xlsx`

This workbook contains the aggregate results for all eight subject programs.
The subject worksheets report the four MFL techniques and the evaluated
variants across the 30 risk formulas and the EXAM and TOP-N metrics.

## `statistical-tests.xlsx`

This workbook contains data used for the Wilcoxon Signed-Rank comparisons. The
unit of analysis is a mutant. Values are averaged over the 30 risk formulas for
each mutant, technique, and metric before paired comparisons are formed.
